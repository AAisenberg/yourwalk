Index model (locked)

Day Index = Footpath Accessibility 60% + Heat & Shade 40%  |  Night Index = Footpath Accessibility 60% + Lighting / After Dark 40%

Higher score = better walking conditions. ~27,458 T1EAM footpath segments (incl. shared use). Scoring unit: street segment (ADR-008).

How the maths works (plain language)

There are two layers of “percent” — don’t mix them up.

  • Layer 1 — the final index: Accessibility counts for 60% of Day Index and Night Index. Heat/shade (day) or lighting (night) counts for the other 40%.
  • Layer 2 — inside Accessibility: We first build one Accessibility score from 0 to 100 for each footpath segment. Width, surface, speed, and graffiti each get their own 0–100 sub-score, then blend into that single number.

Why width + surface + speed + graffiti = 30 + 25 + 25 + 15 = 95%? Those weights are relative importance. The code renormalises them so they always sum to 100% of the base Accessibility score (divide by 0.95). If speed data is missing (~18% of segments), the other three re-scale automatically.

School crossing “+5” = five points on the 0–100 Accessibility scale — not 5%, not a weight. Added only when a school crossing is within 20 m. No crossing → no penalty. On the final Day or Night Index, +5 Accessibility points ≈ +3 index points (because Accessibility is 60% of the index).

Example segment: width 70, surface 90, speed 85, graffiti 100 → base Accessibility ≈ 83. School crossing nearby → 88 (+5 pts). No school crossing → stays 83. If Heat & Shade = 75, Day Index ≈ 0.60 × 88 + 0.40 × 75 = 83 (displayed as 8.3/10 in the app).

Surface buckets (Accessibility)

  • Smooth / firm → 90 — concrete, asphalt, spray seal
  • Moderate → 50 — brick paving, crushed rock, timber (Nikki 3 Jul 2026)
  • Rough / loose → 35 — gravel, rubber
  • Unknown → 50 — TBD, NULL

Explicit gaps — v1.1 deferred

  • General crossings + kerb ramps — not on open data; reduced confidence, not zero penalty
  • Gradient — deferred v1.2 — docs/GRADIENT_DISCOVERY.md
  • Traffic signal phasing — deferred v1.2+ — docs/TRAFFIC_SIGNAL_PHASING.md
  • YourGround, toilets, dog bags — dashboard overlays only, not in index
